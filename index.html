QRYPT Threat Model & Security Rule Specifications
Transparent Cybersecurity Standards

The "Quishing" (QR Phishing) Threat: QR codes are visually opaque machine-readable matrices. Humans cannot read encoded destination URLs by eye. Attackers exploit this blind spot by pasting malicious QR stickers over legitimate restaurant menus, parking payment meters, transit hubs, and bank posters. When scanned, these codes redirect unsuspecting users to credential phishing pages or fraudulent payment destinations.

The 11 Core Heuristic Security Checks

1. Protocol Encryption (HTTPS)

Flags unencrypted HTTP connections that allow network sniffing or MitM tampering.

2. Raw IP Hostname Detection

Detects raw IPv4/IPv6 addresses bypassing standard domain registration and SSL validation.

3. URL Shortener Masking

Identifies redirector services (bit.ly, tinyurl, etc.) masking real phishing landing pages.

4. Brand Impersonation Traps

Flags compound domains masquerading as high-value brands (e.g. secure-login-paytm.com).

5. Typosquatting / Levenshtein Distance

Calculates edit distance against top banking & tech domains to catch lookalikes (e.g. paypa1.com).

6. Homograph / Punycode (xn--)

Detects internationalized domains leveraging Cyrillic or Greek lookalike glyphs.

7. High-Abuse Top-Level Domains (TLDs)

Flags TLDs with disproportionate historical phishing and spam density (.zip, .top, .cam, .xyz).

8. Embedded Credentials & '@' Trick

Catches authority confusion where browser directs to host following the '@' delimiter.

9. Non-Standard Port Numbers

Flags unusual port bindings (:8080, :8443, :22) commonly utilized in disposable malware hosts.

10. Sensitive Action & Incentive Keywords

Detects phishing lures in path/query (login, verify, otp, kyc, cashback, lottery, apk).

11. Excessive Nesting & Path Length

Identifies abnormal URL lengths and excessive subdomain hierarchies designed to deceive mobile address bars.
